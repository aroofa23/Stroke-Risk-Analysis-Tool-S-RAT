Run using Python extension for VSCode<br>
Using Python version 3.10.12<br>
Conducted on Ubuntu 22.04.3 LTS<br>

```bash
git clone $THISREPO
cd $THISREPO
apt-get install python3-pip
apt-get install python3-tk
apt-get install python3-pil python3-pil.imagetk
pip install pandas
pip install scikit-learn
```

## 3. Reproduction

Download and unzip https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset/download?datasetVersionNumber=1<br>
(Kaggle does not allow wget)<br>
Place "healthcare-dataset-stroke-data.csv" in folder 2024_1_Project_20/src<br>

Note: health_care_predictor.py must be run and complete execution before running application.py<br>

1. Follow procedure for installation for desired operating system listed in [installation](#installation).<br>
2. If using VSCode extension for Python, run health_care_predictor.py
3. Upon completion, run application.py.

Note: Below contains commands which are equivalent to using the "Run" button in Python extension for VSCode

For Linux:
```bash
cd $THISREPO
/bin/python3 /your/home_dir/2024_1_project_20/src/health_care_predictor.py
/bin/python3 /your/home_dir/2024_1_project_20/src/application.py
```

For Windows:
```bash
cd $THISREPO
C:/Python310/python.exe C:/your/dir/2024_1_project_20/src/health_care_predictor.py
C:/Python310/python.exe C:/your/dir/2024_1_project_20/src/application.py
```
Data can be found at https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset/download?datasetVersionNumber=1<br>
Output for model will be displayed in terminal<br>
Output for application displayed in GUI<br>
